# OmniCalc Pro - 全能符号计算与可视化工作台

OmniCalc Pro 是一款为科研、工程与数学教育量身定做的全功能高级运算平台。它无缝融合了 **MathJS** 的卓越符号运算能力与 **Google Gemini** 的顶层 AI 推理，并配合高性能 **Canvas 3D** 投影引擎，旨在成为您指尖上最强悍的数学实验室。

## 🌟 核心功能模块

### 1. 📈 全能绘图中心 (Plotting Center)
- **2D 视图控制**: 支持笛卡尔坐标（显式/隐式函数）、参数方程 (x(t), y(t))、极坐标 (r(θ))。支持平滑拖拽平移与滚轮缩放。
- **3D 投影引擎**: 
  - **曲面绘图**: $z = f(x, y)$。
  - **3D 参数曲线**: $[x(t), y(t), z(t)]$，如托拉斯纽结等。
  - **球坐标系**: $r(\theta, \phi)$ 绘图。
  - **交互体验**: 支持鼠标拖拽实时旋转视角、滚轮缩放、深度着色 (Depth-based Shading)。
- **隐式函数**: 采用高效采样算法捕捉轨迹。

### 2. 🔢 符号运算与微处理
- **微积分引擎**: 支持一元/多元导数计算、定积分与不定积分符号化推导。
- **积分变换**: 拉普拉斯变换 (Laplace) 与 傅里叶变换 (Fourier) 的符号解析。
- **方程求解**: 线性方程组、非线性方程以及 常微分方程 (ODE) 的辅助分析。
- **矩阵与张量**: 支持大规模矩阵运算、行列式、特征值计算及基础张量收缩概念。

### 3. ❄️ 复平面视觉 (Complex Plane)
- **实时 Argand 图**: 复数运算结果在复平面上实时打点。
- **转换工具**: 实现代数形式 $a+bi$ 与 极坐标形式 $re^{i\theta}$ 的瞬间切换。

### 4. 📚 物理与特殊函数参考
- **矢量微积分**: 梯度、散度、旋度、拉普拉斯算子的物理含义与常用公式集。
- **特殊函数族**: 勒让德、贝尔、埃尔米特多项式及其物理背景。
- **常数手册**: 内置物理基础常数库。

### 5. 🧠 AI 专家协同
- 集成 **Gemini 2.0 Flash/Pro** 接口，能够解释复杂的数学推导、提供分步解题指南并处理语义化数学请求。

## 🛠️ 技术底座

- **UI 框架**: React 18+ (Vite)
- **样式**: Tailwind CSS (现代响应式布局)
- **运算核心**: MathJS (符号运算与单位处理)
- **可视化**: 
  - 2D: Recharts (数据驱动可视化)
  - 3D: 原生 HTML5 Canvas + 矩阵投影算法 (零依赖 3D 渲染)
- **图标**: Lucide-React

## 🚀 开发者指南

1. **环境准备**: 确保已安装 Node.js。
2. **API 密钥**: 若需启用 AI 功能，请在应用设置或 `.env` 中配置 `GEMINI_API_KEY`。
3. **性能说明**: 3D 绘图采用基于 Canvas 的定点采样，大规模曲面时建议调整步长以获得极致流畅度。
